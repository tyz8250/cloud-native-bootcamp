# Troubleshooting

## 001：S3バケットポリシーのResource指定ミス

### 発生したエラー

CloudFront + OAC用のS3バケットポリシーを保存しようとしたところ、以下のエラーが発生。

`Policy has invalid resource`

### 原因

バケットポリシーの `Resource` に指定したARNのバケット名を打ち間違えていた。

### 対処

S3コンソールで実際のバケット名を確認し、ARNを修正した。

### 学んだこと

- S3バケットポリシーの `Resource` には、正しいリソースARNを指定する必要がある。
- バケット名は手入力せず、AWSコンソールからコピーすることで入力ミスを防げる。
- エラーメッセージから問題のある設定項目を絞り込める。
